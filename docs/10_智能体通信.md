### 智能体通信协议

在已经构建了单体完备的智能体上，如何让智能体与外部世界高效交互？如何让多个智能体相互协作？
该框架主要设计了三种通信协议:
+ MCP (Model Context Protocol): 智能体与工具间的标准化通信
+ A2A (Agent to Agent Protocol): 用于智能体间的点对点协作
+ ANP (Agent Network Protocol): 用于构建大规模智能体网络

#### 为何需要通信协议?
1. **工具集成的困境**：当需要访问新的外部服务，都必须编写专门的Tool类。不仅工作量大，不同开发者的工具无法互相兼容。
2. **能力扩展的瓶颈**：智能体能力被限制在预先定义的工具集内，无法动态发现和使用新的服务。
3. **协作的缺失**：当任务复杂到需要多个专业智能体协作时，只能通过手动编排协调工作。

eg: 智能研究助手
```
# 传统方式：手动集成每个服务
class GitHubTool(BaseTool):
    """需要手写GitHub API适配器"""
    def run(self, repo_url):
        # 大量的API调用代码...
        pass

class DatabaseTool(BaseTool):
    """需要手写数据库适配器"""
    def run(self, query):
        # 数据库连接和查询代码...
        pass

class WeatherTool(BaseTool):
    """需要手写天气API适配器"""
    def run(self, location):
        # 天气API调用代码...
        pass

# 每个新服务都需要重复这个过程
agent.add_tool(GitHubTool())
agent.add_tool(DatabaseTool())
agent.add_tool(WeatherTool())
```
这种方式存在 **代码重复、难以维护、无法复用以及扩展性差** 的问题。
通信协议的核心价值便是解决这些问题：让智能体以**统一的方式**访问各种外部服务，而无需为每个服务编写专门的适配器，如下面代码所示。
```
from hello_agents.tools import MCPTool

# 连接到MCP服务器
mcp_tool = MCPTool()

# 或者连接到专门的MCP服务器
github_mcp = MCPTool(
    sever_command = ["npx", "-y", "@modelcontextprotocol/server-github"]
)
database_mcp = MCPTool(
    sever_command = ["python", "database_mcp_server.py"]
)

# 智能体自动获取所有能力，无需手写
agent.add_tool(mcp_tool)
agent.add_tool(github_mcp)
agent.add_tool(database_mcp)
```

#### 三种协议设计理念比较

##### (1) MCP: 智能体与工具的桥梁
MCP 核心理念是**标准化智能体与外部工具/资源的通信方式**，对于访问文件系统、数据库、github等各种服务，MCP 通过统一的协议规范，让所有服务能够以相同的形式访问。

MCP 不仅是一个RPC (远程过程调用)协议，更重要的是它允许**智能体与工具之间共享丰富的上下文信息**。 

![MCP设计思想](https://raw.githubusercontent.com/datawhalechina/Hello-Agents/main/docs/images/10-figures/10-1.png)

##### (2) A2A: 智能体间的对话
A2A 核心的实际思想是实现**智能体之间的点对点通信**。A2A关注的是智能体之间的协作。这种设计让智能体能够更像人类团队一样对话、协作。

![A2A设计](https://raw.githubusercontent.com/datawhalechina/Hello-Agents/main/docs/images/10-figures/10-2.png)

##### (3) ANP: 智能体网络的基础设施

ANP 是一个概念性的协议框架, 核心的设计理念是构建大规模智能体网络的基础设施。ANP 解决的是 “如何在大规模网络中发现和连接智能体”，在一个包含成百上千个智能体的网络中，如何让智能体能够找到它需要的服务？

![ANP设计](https://raw.githubusercontent.com/datawhalechina/Hello-Agents/main/docs/images/10-figures/10-3.png)

#### hello-agents智能体框架
通信协议自底向上分为三层:
+ 协议实现层：包含了三种协议的具体实现。MCP 基于 FastMCP 库实现，提供客户端和服务器功能；A2A 基于 Google 官方的 a2a-sdk 实现
+ 工具封装层：将协议实现封装成统一的 Tool 接口。
+ 智能体集成层：是智能体与协议的集成点。
